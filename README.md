# 股票分析下單台

本機網頁系統：大盤回測風險 / 減碼建議、台指期近全走勢預測、個股進出場評分 (當沖 / 波段)、支撐壓力圖、
整理完成偵測、類股資金流向、選股掃描，並直接操作你登入的券商網頁 (國票等) 讀庫存、下單、自動停損。

> 本系統是輔助判斷工具，不保證獲利。所有機率都附上歷史回測命中率，命中率不足時會明確警告。

---

## 啟動

雙擊 **`start.bat`** → 等伺服器準備好後，會自動用 Edge 打開 http://127.0.0.1:8000

- 黑色視窗要一直開著，關掉系統就停了 (自動停損、即時推送也會停)
- 已經在跑時再雙擊，只會直接開網頁，不會重複啟動
- **改過程式後要關掉黑色視窗再重開 start.bat 才會生效**
- 第一次啟動會自動建立 Python 環境 (放在 C 槽 `%LOCALAPPDATA%\stock-venv`)

## 畫面總覽

券商帳戶市值與未實現損益、下單帳戶、自動交易狀態。報價有變動會即時推送。

| 分頁 | 用途 |
|---|---|
| **個股進出場** | 輸入代號，選當沖 (日K+5分K+1分K) 或波段 (週K+日K)：總分、各類分數、每個訊號的原因、進出場計畫、大戶/散戶成交、法人籌碼、整理型態、各週期圖。填持有成本可判斷續抱 / 減碼 / 出場 |
| **支撐壓力** | 週K / 日K (短線 + 中長線分開畫) / 5分K / 1分K，標出支撐壓力、多空關鍵價、**未來進出場建議區** (拉回買進、突破追價、停損、目標)、整理箱 |
| **大盤風險/預測** | 上半：大盤回測風險 0~100 + 減碼建議；下半：台指期近全今日走勢預測線 |
| **類股資金** | 題材 (themes.json) 與官方產業的成交金額、資金占比、漲跌幅，各類量最大 / 漲最多個股 |

| **下單 / 持倉** | 手動委託、系統持倉 (即時損益)、**券商實際庫存** (買進均價、損益平衡價、未實現損益)、委託紀錄 |
| **券商帳戶** | 新增 / 管理券商帳戶、預設下單帳戶、送單模式、開啟瀏覽器、擷取頁面、同步帳務 |
| **自動交易** | 自動出場 (停損 / 停利 / 當沖強平)、自動進場、大戶門檻、執行紀錄 |
| **資金與設定** | 當沖 / 波段額度、單筆風險 %、持倉上限、風控 |

## 大盤回測風險 / 減碼建議

判斷「大盤是不是漲多了、快到壓力、該不該減碼、回測會回到哪」。

- **規則訊號** (每項附原因)：月線 / 5 日線 / 季線乖離、日週 RSI、KD 高檔交叉、頂背離、連漲、長上影 / 長黑、
  跌破短均線、離壓力距離、外資現貨買賣超、外資台指期淨留倉、融資增減、期貨逆價差 / 夜盤、**外資資金轉向**
- **歷史相似情況**：加權指數 10 年約 2,400 天，找指標狀態最像現在的 40 天，統計之後 5 天回檔 ≥2% / ≥3%、
  碰 10 日線、10 天內回測月線、隔天收黑的比例，並和「平常」比較
- **回測風險** = 50% 歷史回檔機率 + 50% 規則訊號 → 低 (續抱) / 中 (設停利) / 偏高 (減碼 1/3) / 高 (減碼一半)
- 會用你的券商庫存市值換算建議減碼金額，並列出可能回測的價位 (5 日線、10 日線、月線、支撐)

### 外資資金轉向 (賣半導體、買金融電信)

證交所三大法人個股日報 × 收盤價 → 外資每天在半導體 / 防禦股 (金融 + 中華電、台灣大、遠傳) 的買賣超金額。
依過去一年 236 個交易日回測訂門檻 (平常 10 天內回檔 ≥3% 約 40%、≥5% 約 20%)：

| 等級 | 條件 | 之後 10 天回檔 ≥3% |
|---|---|---|
| +3 | 5 天中 ≥4 天「賣半導體、同時買防禦」，或半導體 5 日賣超 ≥1,300 億且防禦淨買 | 約 65~70% |
| +2 | 5 天中 3 天，或半導體 5 日賣超 ≥1,000 億且防禦淨買 | 約 48~59% |
| +1 | 半導體 5 日賣超 ≥1,000 億 | — |

法人資料約 15:00~16:00 公布。樣本少 (強訊號約 10~20 天)，只當強烈參考。

## 今日走勢預測 (台指期近全)

- 用**台指期近月、夜盤 + 日盤連續**的 5分K (夜盤反映美股 / 國際盤)
- 歷史：期交所前 30 個交易日逐筆成交檔 (自動下載、快取)；盤中：期交所即時 1 分K
- 預測走勢線：找近 30 個交易日中「從夜盤開盤到現在」走法最像的 6 天，取它們之後走勢的平均，再用技術面微調；
  標出 30 分鐘後 / 60 分鐘後 / 本盤收盤的價位與「這條線方向成真的機率」
- **目前回測命中率約 41~50%，沒有明顯預測力**，系統會把機率與預測線往 50% 收斂並警告。適合看區間與支撐壓力，不要單獨依此下單

## 個股

### 評分項目
- **技術面**：均線排列與斜率、MACD、KD、RSI、布林、量價 (帶量突破、價跌爆量、上下影線)、乖離
- **當沖**：VWAP、開盤 15 分鐘區間、1 分K 爆量、昨高昨低、流動性 / 波動條件；日線偏多但盤中轉弱時不追
- **籌碼**：外資 / 投信買賣超與連續天數、融資融券、集保 400 張 / 千張大戶週變化、**大戶 / 散戶成交** (單筆 ≥300 萬元 = 大戶單，判斷大戶吸籌 / 大戶出貨散戶接刀)
- **大盤**：加權指數趨勢、外資大盤買賣超、台指期價差 / 夜盤
- **整理型態**：見下方

### 支撐壓力
轉折高低點、價位成交量分布 (POC)、均線與布林、昨高低收 / VWAP / 開盤區間 (當沖)、週線轉折 (中長線)；
多個依據重疊標示「多重共振」。多方關鍵價 = 近期仍有效的帶量長紅K 低點；空方關鍵價 = 帶量長黑K 高點。

| 週期 | 範圍 |
|---|---|
| 當沖 5分K / 1分K | 前一日 + 今日 / 今日，加上昨高低收、VWAP、開盤區間、±4% 內的日線支撐壓力 |
| 短線波段 | 日K 近 40~60 根 (5/10/20MA、布林) |
| 中長線波段 | 日K 近一年 + 週K 轉折 (60/120/240MA) |

### 整理完成、準備啟動
找近 20~60 天的整理箱，完成度 0~100 = 波動收斂 + 量縮 + 越盤越窄 (VCP) + 均線糾結 + 箱內位置 + 季線趨勢。
階段：整理中 → 整理完成準備突破 → 已啟動 (帶量突破箱頂) / 跌破整理。給啟動價 (箱頂)、失敗停損、等幅目標，圖上畫紫色整理箱。

歷史驗證 (觀察名單 100 檔 × 2 年、9,344 個樣本)：完成度 ≥70 之後 20 天突破箱頂 57.8% (平常 45.2%)、
跌破箱底 23% (平常 36%)、平均最大回檔 −5.9% (平常 −7.4%)。主要價值是避開假突破、降低回檔。

### 張數計算
```
可買股數 = min( 可用額度 ÷ 價格 , 額度 × 單筆風險% ÷ |價格 − 停損| )
```
波段買不起整張可用零股；**零股不能當沖**，當沖只下整張。

## 券商帳戶 (直接操作你的券商網頁)

任何有網頁下單的台灣券商都能接；國票已校正完成，國泰待校正。

1. 「券商帳戶」頁 → 開啟瀏覽器 (系統用正常的 Edge 開，每個帳戶各自一個設定檔，登入與憑證保存在你電腦)
2. 手動登入；第一次在這個 Edge 裡需要申請 / 匯入憑證
3. 新券商：到庫存頁、帳務頁、下單頁各按一次「擷取」→ 跟 Claude 說「幫我校正 (帳戶名稱)」
4. 校正完：盤中每 60 秒自動同步庫存 (股數、買進均價、損益平衡價、未實現損益以券商「未實現損益」頁為準)

### 送單模式
| 模式 | 行為 |
|---|---|
| **你在券商按確定** (預設) | 系統在券商頁填好單、跳出券商確認視窗後停住，你看過內容按「確定」才送出 |
| 系統自動確定 | 系統直接按確定 (自動交易需要) |
| 測試 | 填好後在確認視窗按取消 (校正用) |

送出後系統查券商委託回報，確認有委託書號才記成「已送出」。填單時會逐格核對股號 / 數量 / 價格，不符就停止、不按下單鍵。

## 自動交易

- **自動出場**：觸及停損自動賣出、到目標一先賣一半並把停損移到成本、當沖 13:20 強制平倉
- **自動進場**：當沖每 N 分鐘、波段每天固定時間掃描，符合分數門檻才買，每日新開檔數有上限
- 只會用「系統自動確定」模式的券商帳戶；所有自動單一樣經過額度、張數、價格偏離、漲跌停風控
- 在本機執行：電腦與 start.bat 視窗必須開著

## 限制

- 自動停損靠本機監控後送單：電腦或 start.bat 關掉就不會停損
- 「已送出」代表券商收到委託，是否成交以券商成交回報為準；系統持倉依本系統委託紀錄計算
- 免費成交明細只能在系統開著時累積，5 秒內多筆成交只知道最後一筆張數；FinMind 付費 token (環境變數 `FINMIND_TOKEN`) 可取得完整逐筆
- 集保大戶資料每週一次，第二週起才有增減比較
