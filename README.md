# 股票分析與半自動下單系統

本機網頁介面：個股進出場評分 (當沖 / 波段)、支撐壓力圖、選股掃描、依資金額度算張數、確認後下單。

## 啟動

雙擊 `start.bat`，瀏覽器會打開 http://127.0.0.1:8000

> Python 環境放在 `%LOCALAPPDATA%\stock-venv`，資料 / 帳本 / 設定放在 `%LOCALAPPDATA%\stock-data` (D 槽空間不足)。

## 功能

| 分頁 | 內容 |
|---|---|
| 類股資金 | 題材 (themes.json：低軌、CPO、ABF…) 與官方產業別的成交金額、資金占比、漲跌幅，各類成交量最大 / 漲幅最大個股 |
| 自動交易 | 自動出場 (觸停損賣出、到目標停利、當沖 13:20 強平)、自動進場 (定時掃描買進)、大戶/散戶門檻、執行紀錄 |
| 個股進出場 | 選「波段 (週K+日K)」或「當沖 (日K+5分K+1分K)」，輸出總分、各類分數、每個訊號的原因、進場區/停損/目標/風報比、籌碼表、各週期圖。填持有成本可判斷續抱/減碼/出場 |
| 支撐壓力 | 選週K/日K/5分K/1分K，畫圖並列出支撐、壓力、多方關鍵價、空方關鍵價，以及判斷依據與技術指標判讀 |
| 選股掃描 | 從觀察名單 (預設 100 檔，可用 `%LOCALAPPDATA%\stock-data\watchlist.txt` 自訂) 找做多/做空標的，附建議張數，一鍵建立委託 |
| 下單 / 持倉 | 手動委託、系統持倉 (即時損益)、各券商實際庫存、委託紀錄、當日已實現損益 |
| 券商帳戶 | 新增 / 管理多家券商帳戶、預設下單帳戶、只填單 / 實單切換、擷取頁面、同步帳務 |
| 資金與設定 | **當沖 / 波段各自的可動用額度** (上方「額度 ✎」也能直接改)、單筆風險 %、持倉檔數上限、風控 |

## 評分項目

- **技術面** (每個週期都算)：均線排列與斜率、MACD 交叉/柱狀體、KD 交叉/鈍化、RSI、布林通道 (突破/開口/收斂)、量價 (帶量突破、價跌爆量、上下影線)、乖離
- **當沖額外**：VWAP、開盤 15 分鐘區間突破、1 分K 爆量、昨高昨低、流動性與波動條件；日線偏多但盤中轉弱時不追
- **籌碼**：外資/投信 5 日買賣超與連續天數、融資融券變化、集保 400 張 / 千張大戶持股比例週變化
- **大盤**：加權指數月線/季線、MACD、KD、外資大盤買賣超、盤中指數強弱

## 支撐壓力判斷

1. 波段轉折高低點 (相近價位合併，次數越多越強)
2. 成交量分布 (大量換手區 / POC)
3. 指標價位：5/10/20/60/120MA、布林上中下軌
4. 當沖加：昨高、昨低、昨收、VWAP、開盤區間
5. 多方關鍵價 = 近期仍有效的帶量長紅K 低點；空方關鍵價 = 近期仍有效的帶量長黑K 高點
6. 多個依據重疊 → 標示「多重共振」

## 張數計算 (資金額度)

```
可買股數 = min( 可用額度 ÷ 價格 , 額度 × 單筆風險% ÷ |價格 − 停損| )
```
買得起整張就用張，不夠就用零股 (可關閉)。超過可用額度、持倉檔數、單筆張數、每日筆數、價格偏離 5% 的委託都會被擋。

## 券商帳戶 (支援所有有網頁下單的券商)

「券商帳戶」頁可新增多個帳戶 (例如國票 + 國泰)，每個帳戶各自一個瀏覽器設定檔、各自登入、各自校正：

1. 新增帳戶 → 選券商、填「網頁下單」登入網址
2. 按「開啟瀏覽器」→ 手動登入 (帳密、憑證都在你電腦的瀏覽器設定檔，系統不碰密碼)
3. 切到庫存頁、帳務/交割款頁、下單頁，各按一次「擷取」→ 跟 Claude 說「幫我校正 (帳戶名稱)」
4. 校正後：盤中每 60 秒自動同步庫存與可用餘額；額度上限 = 設定額度與該帳戶可用餘額取小
5. 帳戶預設「只填單不送出」(只填好委託單 + 截圖)，確認無誤後才切「實單送出」
6. 當沖 / 波段可各自指定預設帳戶，下單視窗可臨時改選；平倉會自動送回建倉的帳戶

校正檔在 `brokers/<帳戶id>.json`。有提供程式交易 API 的券商 (永豐 Shioaji、富邦 Neo 等) 之後可另外接 API 型帳戶。

## 即時報價

- 伺服器盤中約每 2 秒合併抓一次 (指數 + 正在看的個股 + 持倉)，台指期約每 2 秒，用 SSE 即時推到網頁
- 資料源本身：證交所個股/指數約每 5 秒更新一筆，台指期約每 1 秒；要逐筆即時需改用券商行情 API
- 證交所 / 期交所免費 API 有頻率限制，問太快會被暫時封鎖 IP → 系統全域限速 (每 1.8 秒最多 1 次)，被擋自動退讓 60 秒
- 個股分析評分與圖每 15/30/60 秒重算 (可選)，支撐壓力圖每 30 秒，類股資金每 2 分鐘

## 支撐壓力的週期

- 當沖：5分K 只看「前一日 + 今日」，1分K 只看今日，另外帶入昨高/昨低/昨收、VWAP、開盤區間、±4% 內的日線支撐壓力
- 短線波段：日K 近 40 根 (5/10/20MA、布林)
- 中長線波段：日K 近一年 + 週K 轉折 (60/120/240MA)
- 每張圖右側黃色區塊 = 未來進出場建議：拉回買進區、突破追價、停損、目標一/二

## 大戶 / 散戶 (成交明細)

單筆成交 ≥ 大戶門檻 (預設 300 萬元) = 大戶單，≤ 5 張 = 散戶單；成交在委賣價 = 外盤買、委買價 = 內盤賣。
判斷「散戶出貨、大戶吸籌」或「大戶出貨、散戶接刀」。免費模式由系統盤中隨即時報價刷新比對收集；
設定環境變數 `FINMIND_TOKEN` (FinMind 付費會員) 可改用完整逐筆成交。

## 限制

- K 線來自 Yahoo，最新一根用證交所即時報價補上 / 更新 (Yahoo 指數日K常缺當天)
- 自動停損由本機監控後送出平倉單：電腦與 start.bat 視窗必須開著，關掉就不會停損
- 零股不能當沖：當沖只下整張，額度買不起 1 張就不下單
- 系統持倉依本系統委託紀錄計算；券商實際庫存需校正帳務頁後才會同步顯示
- 集保大戶資料每週更新一次，系統會逐週累積，第二週起才有增減比較
- 本系統為輔助判斷工具，不保證獲利
